What is FitLater?

FitLater is a structured EDA system that helps you understand your data, identify issues, and take informed preprocessing decisions before building machine learning models.

  • Follows a structured EDA pipeline instead of scattered analysis
  • Goes beyond statistics to identify problems in your dataset
  • Provides clear, reasoned advice on what to fix and why
  • Built to bridge the gap between data understanding and preprocessing
  • Provides a unified Report view combining diagnostics and recommendations

Architecture

Descriptive

Generates foundational statistics and summaries to provide an initial understanding of the dataset structure and distributions

Diagnostics

Analyzes the dataset to identify data quality and statistical issues such as missing values, outliers, and weak relationships

Advisory

Translates detected issues into prioritized recommendations, helping guide preprocessing decisions with clear reasoning

Features

Dataset Overview

Quick summary of missing values, outliers, skew, and duplicates

Column-level Analytics

Detailed statistics and diagnostics for individual columns

Structured Diagnostics

Detects issues like missing values, type mismatches, skew, and correlations

Correlation Detection

Identifies highly correlated column pairs affecting model performance

Priority-based Advisory

Actionable recommendations categorized into high, medium, and low priority

Unified Report Page

Combines summary, diagnostics, and advisory into a single structured view

Analytics Page

The Analytics page provides a detailed, column-level view of your dataset. It allows you to explore individual features, understand their behavior, and identify issues in depth.

Column Selection

Choose any dataset and explore individual columns interactively

Statistical Summary

View key metrics like mean, median, standard deviation, and missing values

Issue Breakdown

See all detected issues for a column, sorted by severity

Distribution Insights

Understand skewness and data spread for numerical features

Categorical Insights

Analyze unique values, dominant categories, and frequency

Visual Analysis

Graphs help you quickly interpret patterns and anomalies

Report Page

The Report page brings together dataset summary, diagnostics, and advisory into a single, structured view. It helps you quickly understand what’s wrong with your data and what actions to take.
